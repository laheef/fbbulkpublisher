Schedule

Stored in UTC, shown in Asia/Karachi.

Scheduling spaces your own authorised content. Don't use it to mass-post repetitive material — that is exactly the behaviour platform rules exist to prevent.

What happens next

  1. PHP stores the post and creates one job per Page.
  2. Your Windows worker claims the job when it is due.
  3. A browser profile for the account opens the Page.
  4. The media uploads, the caption is entered, Publish is pressed.
  5. The result is verified on the Page, then reported back here.

If Facebook asks for a verification, the job pauses and you are notified.

How to connect a machine

  1. Download LinkEasy Facebook Publisher Setup.exe from your workspace.
  2. Run it on a Windows 10/11 64-bit PC. The installer sets up its own Node runtime, Playwright, Chromium and FFmpeg — nothing else is needed.
  3. Launch the app and sign in with your LinkEasy workspace email and password.
  4. The app registers itself, stores its worker token with Windows DPAPI, and starts heart-beating.
  5. Click Connect Facebook Account in the app, sign in to Facebook in the window that opens, and pick your Pages.

Nothing is installed system-wide: the runtime lives inside the application folder, and each Windows user keeps separate profiles, credentials, logs and settings.

Settings

These preferences are handed to your Windows machines on the next heartbeat, so changes apply without reinstalling anything.

Your profile

Automation

Total parallel publishing work on one PC.

Each Chromium instance uses roughly 300–500 MB of RAM.

Traces are stored on your machine only and cleaned up after 14 days. They never contain cookies or credentials, and they are never uploaded here.

Media

With server storage, your machine downloads a file only for the job that needs it and can delete it afterwards — so a laptop never fills up with video.

Windows application

Diagnostics

Save

Machines pick changes up within one heartbeat (about 20 seconds).

Timezone

Schedules are always stored in UTC. Changing this only changes how times are shown.

Publishing provider

  • Authorised browser session (Windows worker)
  • Simulation (nothing is published) — active
